# Task Queue

WORKFLOW section — optional, included only in projects that maintain a task queue.

## Template Text

```
---
TASK QUEUE

Workflow Files/TASKS.txt tracks open work only. No DONE section — completions go in session logs. Read at startup (step 6) and fix any completed items.

Add new items as they come up. On completion, remove from TASKS.txt and note in the session log.
```

## Notes

The step number reference (currently "step 6") must match the actual startup procedure numbering. Include this section only in projects that use a task queue file.
