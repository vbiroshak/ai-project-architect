# Tasks

Per project or sub-project, optional. Active items queue. Open work only, no DONE section. Completions noted in session logs, then removed. Read at startup for project-level queues, at activation for sub-project queues.

Carries freshness lines. Updated immediately when items arise or complete.

## Structural Template

```
[PROJECT] — TASK QUEUE
Last updated: [date] (Session NNN)
Last reviewed: [date]

Open items only. Completions are noted in session logs.

---
ACTIVE

[SUB-PROJECT OR CONTEXT]:
  [ ] [Task description]
  [ ] [Task description]

---
[OPTIONAL SECTIONS]

[Additional categories as needed: ROUTINE MAINTENANCE, FOLLOW UP, BLOCKED, etc. Remove when empty.]
```

## Notes

Keep lean. A growing queue signals items need completing or moving to status files. The queue is for actionable items, not a backlog.

Checkbox format ([ ]) is convention for scanability. Items are removed on completion, not checked off.
